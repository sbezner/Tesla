# Tesla, Inc. - A Brief History

A simple, educational webpage about the history of Tesla, Inc.

## 🌐 Live Site

**Target URL:** https://sbezner.github.io/Tesla/

> ⚠️ **Manual Setup Required:** GitHub Pages needs to be enabled manually once for this repository. See instructions below.

## 📋 Setup Instructions

To enable GitHub Pages for this repository:

1. Go to repository **Settings** → **Pages**
2. Under "Build and deployment":
   - **Source:** Select "GitHub Actions"
3. Save the settings

That's it! The GitHub Actions workflow (`.github/workflows/pages.yml`) will automatically deploy the site on every push to `main`.

## 🔧 Technical Details

- **Static site:** Pure HTML + CSS, no frameworks or backend
- **Deployment:** GitHub Actions workflow configured for automatic deployment
- **Content:** Original brief history of Tesla, Inc. (2003-present)
- **Mobile-friendly:** Responsive design works on phones and tablets

## 📄 Files

- `index.html` - Main webpage with Tesla history timeline
- `style.css` - Styling with modern gradient design
- `.github/workflows/pages.yml` - Automated deployment workflow

## 🚀 Deployment

Once GitHub Pages is enabled (one-time setup above), the site will automatically deploy whenever you push to the `main` branch. The workflow will:

1. Check out the code
2. Configure GitHub Pages
3. Upload the site files
4. Deploy to https://sbezner.github.io/Tesla/
